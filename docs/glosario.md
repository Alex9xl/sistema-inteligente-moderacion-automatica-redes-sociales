# Glosario de Términos

Definiciones de términos técnicos y académicos usados en el proyecto.

| Término | Definición |
|---------|-----------|
| **BETO** | Modelo BERT preentrenado en español por la Universidad de Chile |
| **Fine-tuning** | Ajuste de los pesos de un modelo preentrenado en una tarea específica |
| **Hate speech** | Discurso que ataca o degrada a una persona/grupo por atributos protegidos |
| **Modismo** | Expresión idiomática propia de una variante regional del idioma |
| **Lexicón LATAM** | Recurso léxico de modismos latinoamericanos (instrumento científico) |
| **Tokenización** | Segmentación de texto en unidades mínimas (tokens) |
| **F1-score** | Media armónica de Precision y Recall |
| **Bootstrap** | Remuestreo con reposición para estimar distribuciones |
| **McNemar** | Test estadístico para clasificadores pareados |
| **SHAP** | Shapley Additive exPlanations, método de atribución por Shapley |
| **Manifest V3** | Especificación vigente para extensiones de navegador |
| **Service Worker** | Script de fondo en extensión sin acceso directo al DOM |
| **Content Script** | Script inyectado en el contexto de la página visitada |
| **CORS** | Cross-Origin Resource Sharing, política de seguridad del navegador |

Ver `documentos_extras/INSTRUCCIONES_PROYECTO.md` sección 21 para glosario completo.
